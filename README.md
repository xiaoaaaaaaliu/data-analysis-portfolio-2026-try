一、在线零售用户消费行为分析项目
1.项目背景
基于公开的在线零售数据集，通过 SQLite、Python 与 PowerBI 工具，完成数据清洗、RFM 用户分层与可视化分析，旨在识别核心用户群体、挖掘营收增长点，为运营策略提供数据支撑。
2.数据来源与处理
公开在线零售数据集（包含 2010-12 至 2011-12 的订单数据），共 541,909 条原始记录，涵盖订单号、商品信息、用户 ID、交易时间、金额、国家 / 地区等字段。
数据清洗：剔除退货订单（订单号以 “C” 开头）、负数量记录、缺失用户 ID 的数据，筛选出有效订单数据。
日期格式标准化：使用 Python pd.to_datetime 统一转换交易时间格式，解决 SQLite 日期函数兼容性问题。
入库与指标提取：将清洗后的数据导入 SQLite，通过 SQL 聚合查询生成三类核心表：
月度指标表：包含销售额、活跃用户数、订单数、客单价及环比增长率。
国别销售表：按国家 / 地区汇总销售额与用户数。
RFM 基础表：基于用户交易记录，计算最近一次消费时间（Recency）、消费频次（Frequency）、消费金额（Monetary）指标。
用户分层建模：基于 RFM 模型将用户划分为四类：高价值客户、忠实复购客户、沉睡预警客户、流失低价值客户。
3.核心分析结论
 业务整体表现
月度销售额呈现明显季节性特征，下半年（10-11 月）为销售高峰，12 月受环比下降影响出现回落。
核心市场高度集中：英国贡献超 90% 的销售额，是绝对主力市场，其他国家为补充市场。
整体平均客单价稳定在 400-500 区间，月度活跃用户数随销售高峰同步增长。
用户结构分析
用户分层数量分布：忠实复购客户（1282 人）> 沉睡预警客户（1226 人）> 高价值客户（1113 人）> 流失低价值客户（718 人）。
营收贡献分布：高价值客户以约 25% 的用户数，贡献了超过 50% 的销售额，是营收核心来源；忠实客户为营收基本盘，沉睡与流失用户存在较大召回潜力。

游戏评论情感分析与可视化看板
项目简介
本项目以 TapTap 游戏评论数据为研究对象，完整完成网络爬虫采集→数据清洗预处理→Python 情感分析→Power BI 可视化看板全流程数据分析实战。通过设置情感阈值划分好评、中评、差评，结合饼图、柱状图完成玩家情感分布与星级评分交叉分析，直观挖掘玩家评价倾向与行为特征。

数据处理：Pandas、文本清洗、情感分析
可视化工具：Power BI

分析结论
玩家评价呈现明显两极分化，好评、差评占比偏高，中立中评样本较少；
玩家习惯使用极端星级评分表达态度，1 星多为差评、5 星多为好评；
中间档位评分用户负面情绪偏多，反映游戏仍存在体验优化空间。
